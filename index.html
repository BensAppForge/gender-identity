Student Worksheet (B1 English)

Goal: read data in a fair way. Use kind and respectful language. This topic can be personal for some classmates.

Class rule 1: Talk about data, not people in the room.
Class rule 2: Use "some studies suggest..." not absolute statements.
Class rule 3: It is OK to say "I am not sure yet."
Class rule 4: Listen first, then challenge ideas politely.

Worksheet prompts appear directly under each chart when Worksheet Mode is on.

Teacher View: Lesson Guide (Age 15, CEFR B1)

Use this guide to support careful language, critical thinking, and student well-being. Keep the focus on data analysis, not personal identity.

Safety note: Students may pass on any question without explanation.
Language note: Model neutral phrases like "this dataset suggests..."
Discussion note: Challenge ideas, never people.
Support note: Offer a private check-in option after class.

Suggested 45-Minute Flow

0-5 min
Set class rules and neutral language.
5-18 min
Students complete Worksheet Parts 1-2 in pairs.
18-30 min
Parts 3-4 and source check in groups of 3.
30-45 min
Share revised claims and reflection.

Grouping and Participation

  • Use pairs first (safer speaking environment), then move to groups of three.
  • Assign rotating roles: Reader, Evidence Checker, Language Helper.
  • Allow written responses before speaking to support B1 learners.
  • Offer sentence frames on the board: "The chart shows...", "A limit is...", "Another explanation could be...".

Historical Context & Referral Patterns

Prior to 2010, many clinics reported lower annual referral counts and different age distributions. Since then, pediatric referrals in several countries have increased. These figures describe service use and cannot, on their own, establish prevalence in the wider population.
